Skills are capabilities you toggle on per agent — closer to apps than to plugins. Each skill is a folder with a `SKILL.md` inside: instructions plus a description of when to use it. Turn one on and the agent is told it has that skill. Turn it off and it isn't, so the agent won't reach for it by accident. Froots ships with about ninety, covering browser automation, transcription, image generation, documents, notes apps, messaging apps like Slack and Telegram, smart-home control, and more. Skills that need a missing tool or API key say so and stay off until it's there.

Toggle skills for one agent under **Edit agent → Skills**.

- Skills that need API keys or accounts, and where those go
